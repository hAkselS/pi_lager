This folder contains code dedicated to handling communication between the SeaGlider and the Raspberry Pi. 

More specifically, the SeaGlider treats the Raspberri Pi as a 'logger' device and as such will send commands over serial to the Pi. The Pi uses a persistent script to handle such commands and responds to them accordingly.
